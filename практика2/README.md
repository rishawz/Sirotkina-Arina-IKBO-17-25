# depgraph - визуализатор графа зависимостей Cargo

Практическая работа №2 по дисциплине «Конфигурационное управление»
(РТУ МИРЭА), вариант №24.

Консольное приложение на Python 3 (только стандартная библиотека),
которое строит граф зависимостей пакетов формата Rust (Cargo) без
использования Cargo и сторонних библиотек.

> **Статус разработки:** реализован этап 1 из 5 (конфигурация).
> Остальные этапы будут добавляться отдельными коммитами, а этот
> документ - дополняться.

## Требования и установка

- Python 3.10 или новее (разработка велась на 3.12);
- GNU Make (необязательно, нужен для команд `make run` и `make test`);
- Graphviz (`dot`) - понадобится с этапа 5 для сохранения SVG.

Устанавливать пакеты через pip не нужно: зависимостей нет.

## Запуск и тесты

```bash
make run ARGS="--package serde"      # или: python3 src/main.py --package serde
make test                            # или: PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## Параметры командной строки

| Параметр | Обяз. | По умолчанию | Описание |
|---|---|---|---|
| `--package` | да | - | Имя анализируемого пакета. Обычный режим: имя крейта Cargo (латинские буквы, цифры, `-`, `_`, не длиннее 64, не начинается с цифры или `-`). Тестовый режим: только большие латинские буквы. |
| `--repo` | нет | `https://index.crates.io` | Обычный режим: URL репозитория (`http://` или `https://` с хостом). Тестовый режим: путь к существующему читаемому файлу описания графа. В тестовом режиме параметр обязателен. |
| `--test-mode` | нет | выкл. | Флаг тестового режима: `--repo` трактуется как путь к файлу. |
| `--output` | нет | `graph.svg` | Имя файла изображения графа: `<имя>.svg`, каталог должен существовать. |
| `--ascii-tree` | нет | выкл. | Флаг: вывести зависимости в виде ASCII-дерева. |
| `--filter` | нет | пусто | Не учитывать пакеты, в имени которых есть подстрока. Пустая строка - фильтр выключен. Пробелы не допускаются; в тестовом режиме - только большие латинские буквы. |

На этапе 1 (и только на нём) приложение после проверки параметров
печатает их в виде `ключ: значение`. При ошибке в параметрах сообщение
`Ошибка: ...` выводится в stderr, код завершения равен 2.

## Примеры

Корректный запуск:

```console
$ python3 src/main.py --package serde
package: serde
repo: https://index.crates.io
test-mode: False
output: graph.svg
ascii-tree: False
filter:

$ python3 src/main.py --package A --test-mode --repo graph.txt --filter C
package: A
repo: graph.txt
test-mode: True
output: graph.svg
ascii-tree: False
filter: C
```

Некорректный запуск (код завершения 2):

```console
$ python3 src/main.py
Ошибка: the following arguments are required: --package
$ python3 src/main.py --package serde --repo ftp://x
Ошибка: URL должен начинаться с http:// или https://: 'ftp://x'
$ python3 src/main.py --package A --test-mode
Ошибка: в тестовом режиме нужно указать --repo
$ python3 src/main.py --package serde --output g.png
Ошибка: имя файла изображения должно иметь вид <имя>.svg: 'g.png'
```

## Структура

```
src/main.py       точка входа
src/config.py     разбор и проверка параметров
tests/            тесты (unittest), включая test_style.py - автопроверку
                  ограничений методички (длина строк и функций, число
                  аргументов, сложность, docstring, магические числа)
Makefile          команды run и test
```
